# 技能投送与命中判定规则

Status: Draft
Version: v1.0
Owner: Design
Last Updated: 2026-05-23
Scope: 战斗技能的投送方式、飞行运动、命中判定、穿透机制、弹射机制的完整规则定义。数值参数见 `values/skill-values.csv`。
Related: `combat-attributes-resolution.md`; `projectile-v1-taxonomy.md`; `combat-core-baseline.md`; `skill-warning-zone-spec.md`

---

## 1. 总述

本文定义战斗系统中所有技能从"释放成功"到"命中结算"之间的完整运行规则。涵盖以下核心命题：

1. **投送方式**：技能如何将伤害传递到目标（即时 vs 飞行道具）
2. **飞行运动**：飞行道具的运动模式（轨迹路线型 vs 追踪型）
3. **命中判定**：飞行道具何时、如何判定命中目标
4. **穿透机制**：飞行道具穿过多个目标时的行为规则
5. **弹射机制**：飞行道具命中后重定向到新目标的行为规则
6. **未命中处理**：飞行道具未命中任何目标时的处理规则
7. **伤害结算时机**：伤害、怒气、状态效果的实际施加时间点

### 1.1 设计原则

- **飞行道具是伤害的真正载体**：投射物命中目标时才施加伤害，而非技能释放时
- **近战/瞬发技能即时命中**：无飞行道具的技能在释放瞬间完成全部结算
- **配置驱动**：每个技能的投送方式、追踪参数、穿透属性、弹射行为均由独立配置决定，不设全局硬编码规则
- **Modifier 可干预**：穿透属性、弹射参数等可被技能改造效果（Modifier）在运行时修改

## 2. 技能投送方式（Delivery Type）

每个技能有一个 `delivery_type` 属性，决定其伤害传递方式。

### 2.1 即时命中型（Instant）

**定义**：技能释放成功瞬间，立即完成命中判定和伤害结算。无飞行道具生成。

**适用场景**：
- 近战攻击（刀光、挥砍）
- 以施法者为中心的瞬发 AOE（冰环、火焰之手等范围技能）
- 无投射物阶段的任何技能

**结算流程**：
```
释放 → 即时命中判定 → CombatResolver.resolve_attack() → take_damage()
                       → 怒气生成 → 状态效果施加
```

### 2.2 投射物命中型（Projectile）

**定义**：技能释放时生成一个或多个飞行道具（投射物），投射物沿特定运动规则飞行，命中合法目标时才进行伤害结算。

**适用场景**：
- 所有发射飞行道具的技能（火球术、导弹风暴、幽灵火骷髅、闪电链等）

**结算流程**：
```
释放 → 生成投射物（携带伤害参数）→ 飞行 → 命中检测
    → 命中时：CombatResolver.resolve_attack() → take_damage()
              → 怒气生成 → 状态效果施加 → VFX
    → 未命中：投射物消失，不造成伤害
```

### 2.3 投送方式判定规则

| 条件 | delivery_type | 说明 |
|------|--------------|------|
| 技能生成投射物（effect_type = emit_projectile） | projectile | 投射物是伤害载体 |
| 技能无投射物（近战、瞬发 AOE、光束等） | instant | 释放即命中 |

投送方式由 SkillDef 的 `delivery_type` 字段配置，每个技能独立设定。

## 3. 飞行道具运动模式

投射物命中型技能的飞行道具，按运动模式分为两大类：**轨迹路线型**和**追踪型**。

### 3.1 轨迹路线型

**核心特征**：投射物在释放成功的那一刻，其完整飞行路线即已确定。飞行过程中不因目标移动而改变路线。除非受到 Modifier 的路线改造效果（如 CurvedPathModifier），否则路线始终不变。

**子类型**：

| 运动模式 | trajectory_type | 说明 |
|---------|----------------|------|
| 直线匀速 | 0 | 固定方向，匀速飞行 |
| 贝塞尔曲线 | 1 | 弧线飞行，控制点在发射时计算，终点为发射时目标位置的快照 |
| 正弦波 | 2 | 直线运动叠加垂直方向的正弦偏移 |

**路线确定性保证**：
- 直线型：方向在发射时确定，之后不改变
- 贝塞尔曲线型：起点、控制点、终点在发射时全部计算完成，之后按参数方程运动
- 正弦波型：振幅、频率在发射时确定，运动叠加在直线路径上
- 即使 Modifier 在飞行途中改变了路线（如 CurvedPathModifier），新路线也是确定的

**命中检测**（详见第 4 章）：轨迹路线型投射物在飞行过程中，每帧检测其与目标的距离。

### 3.2 追踪型

**核心特征**：投射物在飞行过程中定期修正飞行方向，朝向目标当前位置逐渐转向。类似于追踪导弹的制导机制。

#### 3.2.1 路线修正机制

投射物发射时有一个初始飞行方向。在飞行过程中：

1. **每帧**计算投射物当前位置到追踪目标当前位置的**理想方向**
2. 计算当前飞行方向与理想方向的**角度差**
3. 用 `turn_rate`（rad/s）限制本帧的**实际转向角度**：
   ```
   actual_turn = clamp(angle_diff, -turn_rate * dt, turn_rate * dt)
   ```
4. 将飞行方向旋转 `actual_turn` 角度
5. 沿新方向继续飞行

**turn_rate 的意义**：
- turn_rate 越大，投射物转向越快，追踪越紧密（强追踪）
- turn_rate 越小，投射物转向越慢，轨迹越弯曲飘逸（弱追踪）

#### 3.2.2 命中精准范围（hit_precision_radius）

追踪型投射物的命中判定不要求投射物精确碰到目标身体，而是使用一个**精准范围**参数：

```
命中条件：投射物与目标的距离 < hit_precision_radius + current_radius
```

- `hit_precision_radius = 0`：必须精确碰到目标才算命中（等效于传统必中，前提是速度足够追上）
- `hit_precision_radius > 0`：投射物进入目标周围一定范围内即算命中（擦身爆炸）

**设计意义**：

| hit_precision_radius | 效果 | 设计用途 |
|---------------------|------|---------|
| 0 | 精确命中，投射物必须碰到目标 | 必中技能，高精度追踪 |
| 10-20 px | 擦身命中，投射物靠近即爆 | 大多数追踪技能的默认配置 |
| 30-50 px | 远程引爆，投射物在较远处即爆 | 大范围爆炸型追踪弹 |

当 `hit_precision_radius > 0` 时，虽然投射物最终都朝着目标飞，但有些正好命中身体、有些擦身而过在旁边爆炸。这种效果让游戏有更大的运动空间，单位的走位有了实际意义。

命中时的伤害效果可以配置为**范围伤害**（在精准范围内造成 AOE），从而补偿命中精度不足，形成"追踪 + 擦身爆炸 + 范围杀伤"的完整体验。

#### 3.2.3 弱追踪 vs 强追踪

追踪型进一步区分为弱追踪（C 型）和强追踪（D 型）。核心差异在 turn_rate 和游荡行为：

| 参数 | 弱追踪（C 型） | 强追踪（D 型） |
|------|--------------|--------------|
| turn_rate | 1-2 rad/s | 4-6 rad/s |
| 游荡范围 | 大 | 小 |
| 游荡衰减 | 慢（~2s） | 快（~0.4s） |
| 命中时间 | 较长 | 较短 |
| 轨迹特征 | 弯曲、飘逸 | 紧凑、直接 |

弱追踪的游荡行为（详见 `projectile-v1-taxonomy.md` §4a.3）：
- 投射物有独立的游荡冲动计时器（200-400ms 间隔）
- 触发时给投射物一个垂直于运动方向的瞬时速度冲击
- 约 30% 概率附加螺旋力，产生 1-2 圈螺旋轨迹
- 随时间推移，游荡冲动逐渐收敛，投射物回归追踪

### 3.3 运动模式配置

运动模式由以下 SkillDef 字段组合决定：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| trajectory_type | int | 0 | 0=直线, 1=贝塞尔, 2=正弦波 |
| tracking_enabled | bool | false | 是否启用追踪 |
| turn_rate | float | 0.0 | 追踪转向速率（rad/s） |
| hit_precision_radius | float | 0.0 | 命中精准范围（px） |

当 `tracking_enabled = true` 时，投射物使用追踪运动模式，每帧修正方向。`trajectory_type` 在追踪模式下被忽略（追踪有自己的方向逻辑）。

## 4. 命中判定规则

### 4.1 命中检测方法

所有投射物使用**距离检测**（非 Area2D 碰撞、非射线检测）：

```gdscript
# 每帧在 _process() 中执行
var dist := projectile_position.distance_to(target_position)
if dist < hit_threshold:
    # 命中
```

### 4.2 命中阈值

命中阈值由投射物类型决定：

| 投射物类型 | 命中阈值 | 说明 |
|-----------|---------|------|
| 轨迹路线型 | `current_radius + 10.0` | 固定偏移量 |
| 追踪型 | `hit_precision_radius + current_radius` | 由技能配置决定 |

### 4.3 目标有效性

命中检测前，先验证目标有效性：

```
if target 为 null 或已被释放（死亡/移除）:
    投射物销毁（destroy）
    不执行命中效果
    不造成伤害
```

### 4.4 目标命中流程

命中后，根据投射物的穿透和弹射属性，走不同的后续流程（详见第 5、6 章）。

### 4.5 投射物最大生命周期

所有投射物有 5 秒最大生命周期安全网。超时后：

- 投射物销毁
- **不执行命中效果**
- **不造成伤害**

## 5. 穿透机制（Pierce）

### 5.1 定义

穿透属性允许飞行道具在命中一个目标后，不消失而是继续飞行，可以命中路径上的更多目标。

### 5.2 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| pierce_enabled | bool | false | 是否可穿透目标 |
| pierce_count | int | 0 | 最大穿透次数。-1 = 无限穿透 |

### 5.3 穿透行为规则

#### 5.3.1 基本穿透

当 `pierce_enabled = true` 时：

1. 投射物命中第一个合法目标 → 执行命中效果（伤害、怒气、状态、VFX）
2. 投射物**不消失**，继续沿当前方向飞行
3. 投射物将已命中的目标加入**命中排除列表**（`hit_targets`），同一目标不会被重复命中
4. 投射物在后续飞行中继续检测新的合法目标
5. 每命中一个新目标：`pierce_count -= 1`
6. 当 `pierce_count` 降至 0 时，命中最后一个目标后销毁

#### 5.3.2 无限穿透

当 `pierce_count = -1` 时，投射物可以无限穿透目标，直到以下任一条件满足：
- 飞行 5 秒超时（最大生命周期）
- 飞出场景边界（见 §5.4）
- 受到 Modifier 修改导致 pierce_count 变为有限值

#### 5.3.3 无穿透

当 `pierce_enabled = false` 时，投射物命中第一个合法目标后执行命中效果，然后进入弹射判定（如有）或销毁。

### 5.4 穿透与场景边界

穿透属性**只作用于合法战斗目标**（敌方单位、英雄单位）。

飞行道具碰到以下障碍时**立即销毁，且不执行命中效果**：
- 场景边界（地图边缘的不可通行区域）
- 建筑物/障碍物（如果存在）

穿透不意味着可以穿过墙壁和边界。

### 5.5 命中排除列表

穿透模式下，投射物维护一个 `hit_targets` 列表：

```
命中目标时:
    if target 在 hit_targets 中:
        跳过（不重复命中）
    else:
        加入 hit_targets
        执行命中效果
        pierce_count -= 1
```

这确保投射物穿过同一目标只触发一次命中，不会对同一敌人造成多次穿透伤害。

### 5.6 穿透与 Modifier

穿透属性可被 Modifier 在运行时修改：

- 某个 Modifier 可以给投射物追加穿透能力：`chain.pierce_enabled = true; chain.pierce_count += 3`
- 某个 Modifier 可以移除穿透能力：`chain.pierce_enabled = false`
- 某个 Modifier 可以增减穿透次数：`chain.pierce_count += N`

**典型场景**：某个友军光环可以给技能增加 3 次穿透效果，原本不穿透的技能获得了穿透能力。

## 6. 弹射机制（Bounce）

### 6.1 定义

弹射属性允许飞行道具在命中一个目标后，重定向到附近的新目标继续飞行。

### 6.2 弹射行为规则

1. 投射物命中目标 → 执行命中效果（伤害、怒气、状态、VFX）
2. 检查 `bounce_remaining > 0`
3. 在附近搜索下一个合法目标（排除当前目标）
4. 如果找到新目标：
   - `bounce_remaining -= 1`
   - 投射物方向重定向到新目标
   - 继续飞行并检测命中
5. 如果没有找到新目标：投射物销毁

### 6.3 弹射伤害系数

每个技能独立配置弹射伤害系数 `bounce_damage_scale`：

```
弹射命中时实际伤害 = chain.damage × bounce_damage_scale
```

| bounce_damage_scale | 效果 | 适用场景 |
|--------------------|------|---------|
| 1.0 | 不衰减 | 弹射伤害与首次命中相同 |
| 0.7 | 衰减 30% | 弹射伤害逐步降低 |
| 1.5 | 增强 50% | 弹射伤害比首次更高 |

**不设全局硬编码规则**。每个技能的弹射伤害系数独立配置，由设计需求决定。

`bounce_damage_scale` 也可被 Modifier 在运行时修改。

### 6.4 弹射与穿透的关系

弹射和穿透是两种不同的命中后行为：

| 机制 | 命中后行为 | 方向 | 适用场景 |
|------|----------|------|---------|
| 穿透 | 继续沿原方向飞行 | 不变 | 直线/曲线型投射物穿过多个目标 |
| 弹射 | 重定向到新目标 | 改变 | 闪电链等跳跃型技能 |

两者可以独立配置，也可以共存于同一技能（但通常不会同时需要）。

## 7. 伤害结算时机

### 7.1 即时命中型技能

```
释放瞬间:
  1. CombatResolver.resolve_attack() 计算伤害
  2. target.take_damage()
  3. caster 怒气生成（damage × 0.15）
  4. 状态效果施加
```

### 7.2 投射物命中型技能

```
投射物命中目标时:
  1. CombatResolver.resolve_attack() 计算伤害
  2. target.take_damage()
  3. caster 怒气生成（damage × 0.15）
  4. 状态效果施加
  5. VFX 触发
```

**关键区别**：伤害计算和所有后续效果（怒气、状态）都延迟到投射物命中时。

### 7.3 怒气生成

怒气在伤害施加时同步生成：

- **即时型**：释放时立即生成怒气
- **投射物型**：命中时才生成怒气
- **未命中**：不生成怒气

### 7.4 状态效果施加

状态效果（燃烧、冰冻、感电、中毒、眩晕等）在伤害施加时同步施加：

- **即时型**：释放时立即施加
- **投射物型**：命中时才施加（被火球打到才着火，不是看到火球就着火）
- **未命中**：不施加状态效果

## 8. 未命中处理

### 8.1 定义

投射物未命中 = 投射物在其生命周期内没有命中任何合法目标。

### 8.2 未命中场景

| 场景 | 处理 |
|------|------|
| 投射物飞行超时（5 秒） | 投射物销毁，不造成伤害 |
| 目标死亡/被释放 | 投射物销毁，不造成伤害 |
| 投射物飞出场景边界 | 投射物销毁，不造成伤害 |
| 追踪型投射物速度追不上目标 | 投射物最终超时销毁，不造成伤害 |

### 8.3 未命中结果

```
投射物未命中:
    - 不造成伤害
    - 不生成怒气
    - 不施加状态效果
    - 不触发命中 VFX
    - 投射物静默消失（或播放"未命中"消散动画，如适用）
```

## 9. Modifier 对投送/命中属性的干预

所有投送和命中相关属性均可被 Modifier 系统在运行时修改。

### 9.1 可修改的属性

| 属性 | Modifier 示例 |
|------|-------------|
| trajectory_type | CurvedPathModifier 改变飞行轨迹 |
| tracking_enabled | 给投射物追加追踪能力 |
| turn_rate | 增减追踪转向速率 |
| hit_precision_radius | 扩大或缩小命中精准范围 |
| pierce_enabled / pierce_count | 给投射物追加或移除穿透能力 |
| bounce_remaining | 增减弹射次数 |
| bounce_damage_scale | 修改弹射伤害系数 |
| speed | 加速或减速投射物 |

### 9.2 修改时机

Modifier 在 SkillExecutor 解析阶段（技能释放时）修改 ExecutionChain 的属性。修改后的值在投射物飞行全程生效。

部分 Modifier 可能需要在飞行途中动态生效（如友军光环），这属于更高级的 Modifier 类型，基础架构应预留扩展接口。

## 10. 配置结构

### 10.1 SkillDef 字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| delivery_type | String | "projectile" | "projectile" / "instant" |
| tracking_enabled | bool | false | 是否追踪 |
| turn_rate | float | 0.0 | 追踪转向速率 rad/s |
| hit_precision_radius | float | 0.0 | 命中精准范围 px |
| pierce_enabled | bool | false | 是否可穿透 |
| pierce_count | int | 0 | 穿透次数，-1=无限 |
| bounce_damage_scale | float | 1.0 | 弹射伤害系数 |

### 10.2 CSV 数值

以上字段同步在 `values/skill-values.csv` 中配置，支持热调不改动代码。

### 10.3 现有技能配置参考

## 11. 术语表

| 术语 | 英文 | 含义 |
|------|------|------|
| 投送方式 | Delivery Type | 技能传递伤害到目标的方式：即时或投射物 |
| 轨迹路线型 | Trajectory | 投射物路线在释放时确定，飞行中不改变 |
| 追踪型 | Tracking / Homing | 投射物飞行中定期修正方向，追踪目标 |
| 命中精准范围 | Hit Precision Radius | 追踪型投射物的命中判定距离阈值 |
| 穿透 | Pierce | 投射物穿过目标后继续飞行的能力 |
| 弹射 | Bounce | 投射物命中后重定向到新目标的能力 |
| 命中排除列表 | Hit Targets | 已被穿透型投射物命中的目标列表，防重复命中 |
| 弹射伤害系数 | Bounce Damage Scale | 弹射命中时伤害的乘数 |
