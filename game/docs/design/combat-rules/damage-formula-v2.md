# 伤害计算公式 v2 — 乘法公式体系

> 版本: v2.0 | 更新: 2026-05-27 | 状态: 定稿

---

## 一、核心公式

```
最终伤害 = 基础伤害 × 防御系数 × 元素系数 × 暴击系数 × 命中判定系数
```

---

## 二、基础伤害（递减收益）

```
有效攻击力 = 施法者攻击力 × ATK_CONST / (ATK_CONST + 施法者攻击力)
基础伤害 = 技能固定值 + min(技能系数 × 有效攻击力, 成长上限)
```

| 参数 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `技能固定值` | float | SkillDef.base_damage | 保底伤害，不受攻防影响 |
| `技能系数` | float | SkillDef.skill_coefficient | 每点有效攻击的转化比率 |
| `施法者攻击力` | float | CombatantStats.attack | 角色的攻击属性 |
| `成长上限` | float | SkillDef.growth_cap | 可选安全阀，0=无上限，默认 99999 |
| `ATK_CONST` | float | 全局常量 | 攻击力拐点，控制递减曲线（=8000） |

**递减收益说明：**

`有效攻击力` 是一个软上限函数——攻击力低于 ATK_CONST 时近似线性，高于 ATK_CONST 时边际递减：

| 攻击力 | 有效攻击力 | 效率 | 说明 |
|--------|-----------|------|------|
| 300 | 218 | 73% | Ironwall (坦克 0.6x) |
| 500 | 381 | 76% | 普通小怪 / Moss (辅助 1.0x) |
| 750 | 545 | 73% | Ember (脆皮 1.5x) |
| 900 | 643 | 71% | 精英怪 (1.8x) |
| 1500 | 1071 | 71% | Boss (3.0x) |
| 8000 | 4000 | 50% | 拐点：效率降为一半 |

**默认公式（成长上限 = 0，即无上限）：**
```
有效攻击力 = 施法者攻击力 × 8000 / (8000 + 施法者攻击力)
基础伤害 = 技能固定值 + 技能系数 × 有效攻击力
```

**成长上限规则：**
- `growth_cap = 0`：无上限，`基础伤害 = 技能固定值 + 技能系数 × 有效攻击力`
- `growth_cap > 0`：硬截断，`基础伤害 = 技能固定值 + min(技能系数 × 有效攻击力, 成长上限)`

---

## 三、防御系数

```
防御系数 = DEF_CONST / (DEF_CONST + 目标防御力)
```

**全局常量：DEF_CONST = 10000**

防御系数曲线：

| 目标防御力 | 防御系数 | 实际减伤 |
|-----------|---------|---------|
| 0 | 1.000 | 0% |
| 1111 | 0.900 | 10.0% |
| 1765 | 0.850 | 15.0% |
| 2500 | 0.800 | 20.0% |
| 4286 | 0.700 | 30.0% |
| 6667 | 0.600 | 40.0% |
| 10000 | 0.500 | 50.0% |

## 四、后续乘法系数

### 4.1 元素系数（已有，保持不变）

```
元素系数 = element_damage_mult(damage_type, target_stats, combat_params)
```

读取目标对应元素抗性，经 CombatResolver 的 `element_damage_mult()` 函数计算。

### 4.2 暴击系数（已有，保持不变）

当命中判定为暴击时：`暴击系数 = 1.0 + crit_power / 100.0`

## 五、完整计算流程图

```text
施法者攻击力 × 8000/(8000+攻击力)
                ↓
          有效攻击力（递减收益）
                ↓
技能固定值 + (系数×有效攻击力)  [受成长上限截断]
                ↓
          基础伤害
                ↓
     基础伤害 × 10000/(10000+防御)
                ↓
        穿透防御后伤害
                ↓
      × 元素系数(基于目标抗性)
                ↓
      × 暴击系数(如果暴击)
                ↓
      × 命中判定系数(Hit/Glance/Deflect/Miss)
                ↓
          最终伤害 → target.take_damage()
```

## 七、改动清单

### 7.1 `CombatantStats` 新增字段

```gdscript
var attack: float = 100.0
var defense: float = 100.0
```

各英雄静态构造方法补充初始值。

### 7.2 `SkillDef` 新增字段

```gdscript
@export var skill_coefficient: float = 1.0   # 技能伤害系数
@export var growth_cap: float = 99999.0       # 成长上限（0=无上限，默认 99999）
# base_damage 保留作为固定值
```

### 7.3 `CombatResolver.resolve_attack()` 修改

入参从 `base_damage: float` 改为接收 `attacker_attack: float` 和 `defender_defense: float`，内部计算：

```gdscript
# 递减收益：有效攻击力
var effective_attack := attacker_attack * ATK_CONST / (ATK_CONST + attacker_attack)
var growth := skill_coefficient * effective_attack
if growth_cap > 0:
    growth = minf(growth, growth_cap)
var base_damage := fixed_damage + growth
var defense_mult := DEF_CONST / (DEF_CONST + defender_defense)
var final_damage := base_damage * defense_mult
# ... 后续元素/暴击/命中系数不变 ...
```

### 7.4 `CombatParams` 新增

```gdscript
const DEF_CONST: float = 10000.0   # 防御系数拐点
const ATK_CONST: float = 8000.0    # 攻击力递减收益拐点
```
